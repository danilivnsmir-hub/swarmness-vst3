# Swarmness — список графических ассетов для генерации

Этот текст можно целиком вставить в ChatGPT. В нём перечислены все элементы интерфейса: размеры, состояния, имена файлов и что на каждом должно быть нарисовано.

## Общие правила (для всех файлов)

- **Стиль:** «некро-пчёлы». Тёмный металл, воск и мёд, соты, лёгкая органика и гниль (потёки мёда, трещины). Хоррор-атмосфера, но без гора. Референс — нынешний интерфейс.
- **Палитра:**
  - фон — почти чёрный, коричневатый, от `#0e0b08` до `#1a140e`;
  - акцент — мёд/янтарь `#f29a1f`, яркий `#ffc24a`, глубокий `#b35f0c`;
  - металл — тёмная сталь `#2a2c30`–`#8c8f94`;
  - индикаторы — зелёный `#5cff7a` и красный `#ff3b2f`.
- **Формат:** PNG, 32 бита, прозрачный фон везде, кроме полноэкранного фона.
- **Разрешение:** всё рисуется **в 2 раза крупнее**, чем на экране (интерфейс масштабируется до 200%). В таблицах сразу указан размер файла, то есть уже ×2.
- **Без текста, цифр, логотипов и брендов.** Подписи, значения, шкалы, графики и дуги значений рисует код поверх картинки.
- **Свет:** сверху слева, одинаковый на всех элементах. Вид строго спереди, без перспективы. Тени только внутри границ файла. Внешние тени и свечения должны умещаться в прозрачные поля (не меньше 8 px с каждой стороны).
- Элементы, которые растягиваются по размеру (панели, кнопки), делаются по **9-slice**: углы и рамка по краю, середина однородная, без рисунка по центру. Для каждого такого файла указана ширина нерастягиваемого угла.
- Если у элемента есть состояния, каждое состояние — отдельный файл того же размера, с тем же положением элемента внутри (кадры должны совпадать пиксель в пиксель).

## 3. Ручки (главный элемент)

Код вращает крышку ручки сам. Цветную дугу значения вокруг ручки тоже рисует код. Поэтому нужны неподвижное основание и крышка с указателем, **смотрящим строго вверх (12 часов)**.

| Файл | Размер | Что это |
|---|---|---|
| `knob_base.png` | 160×160 | Неподвижная «юбка» и тёмная впадина под ручкой: кольцо с 11 рисками шкалы от 7:30 до 4:30, шаг ровно 27° (дуга 270°, разрыв внизу 90°), центр рисок — центр файла. |
| `knob_cap.png` | 112×112 | Вращающаяся крышка: тёмный металл с шестигранной гранью сверху и янтарной риской-указателем вверх. Свет **не должен вращаться**, поэтому блики лучше держать слабыми и симметричными. |
| `knob_cap_small.png` | 80×80 | То же для маленьких ручек (A/B MIX, ручки в плотных сетках). |
| `knob_big_cap.png` | 144×144 | Крупная ручка для INPUT / VOLUME внизу окна: та же крышка, чуть богаче детали. |

Необязательно: `knob_cap_hover.png` — та же крышка, чуть ярче. Если его не будет, код подсветит сам.
